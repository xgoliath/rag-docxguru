# DocxGuru

Live Demo: https://rag-doxguru.streamlit.app/

DocxGuru is a simple Retrieval-Augmented Generation (RAG) chatbot that allows users to upload PDF documents, process them into searchable chunks, and ask questions about their content.

The project uses **Streamlit** for the user interface and deployment, **ChromaDB** for vector storage and retrieval, **Sentence Transformers** for document embeddings, and **Groq** for generating responses.

Built as a personal project to explore practical applications of RAG and document-based question answering.
